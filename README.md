# 🚀 URL Shortener

A simple and efficient URL Shortener built using Node.js, Express, and MongoDB. It allows users to generate short links and seamlessly redirect to original URLs.

Built to understand backend fundamentals like routing, database design, and redirection logic.

## ✨ Features

* Generate short URLs from long links
* Redirect to original URL using short code
* Unique short ID generation
* MongoDB-based URL storage
* Clean and simple backend architecture
* A separate role-based authorization in which admin can see all URLs and who generated the URL in ADMIN PANEL!

---

## 🛠️ Tech Stack

* Node.js, Express.js
* MongoDB (Mongoose)
* Short ID generation (nanoid / custom logic)

---

## ⚙️ Setup

git clone https://github.com/hepisonii/url-shortener.git
cd url-shortener
npm install

Create a `.env` file:

PORT=3000
MONGO_URI=your_mongo_url

Run the app:

npm start
